One word a grandma would text about AI: "robit" — the typo she actually makes when she means "robot". Warm, a little baffled, funny on its own, and tied straight to robots. The program scores a shortlist of candidate words against the judge's five criteria, in the judge's priority order, and writes the winner to /output/entry.txt.

## Run it

```sh
python3 main.py
```
